# 新手逐步引导

本包提供完整新手引导与公开教程，不依赖任何私人说明文档。当前是六列产品，不默认加入旧加餐的七字段、退款或月收入问卷。

先从建立本人账本开始，CLI检查放在手机OCR入表成功后的安装最后一步；每轮用“当前步骤／入口／操作／完成标志”，只推进当前一步。用户已完成的部分复用，必要手机操作给明确完成标志，不把口头完成当接口验收。

## 1. 建立本人账本

已有本人六列账本时直接复用。没有时按 [空白账本](blank-ledger.md) 在飞书界面创建「我的记账本」与「具体开支」，使用随包字段结构，不需要作者链接。用户自己提供已脱敏模板时才整份复制到本人的云空间。

核对六列日期/文本内容/收支类型/金额/具体花费项目/消费类型；视图和仪表盘按需要补齐，普通字段与原生AI提取分别验收。不复制任何人的真实账单，已有账本不清空。核对链接确属本人，表名「具体开支」；缺项先核对，不自行重建已有布局。

## 2. 创建并发布应用

打开 [开发者中心](https://open.feishu.cn/app) → 企业自建应用 → 创建，名称可为“智能记账助手”。这不是群自定义webhook机器人。

权限管理 → 开通权限 → 应用身份权限 → 搜索base:record:create（新增记录）。实际Agent工具需要读取/更新时按当前接口补充；CLI v3权限不照抄旧v1。版本管理与发布 → 创建版本 → 保存并发布；有管理员审核时等待通过，改权限后按平台要求重新发布。

只在宿主确需应用机器人发消息时启用相关能力，默认不要求webhook或加入群。

## 3. 凭据与副本授权

App ID、App Secret由用户保存到密码管理器并自行填手机，聊天不索要Secret。详见 [填写对照](credentials.md)。

**添加应用的入口只有：打开自己的账本副本 → 右上角「・・・」更多菜单 → 添加文档应用 → 选择刚发布的应用。** 不把“分享/协作者”当成添加或安装文档应用入口。

添加后核对该应用确已关联本人副本，按实际界面确认编辑权限，最终通过新增记录测试验证。入口缺失先查副本所有者、应用同一组织、发布状态及可用范围；API权限和文档授权都需要。

## 4. 修改快捷指令参数

复用本人可信且无作者凭据的快捷指令；没有安装文件时按 [从零创建](shortcut-build.md) 引导，不让用户寻找私人资源。标记版进入配置页面，**直接点击快捷指令进入编辑**，找到三处 **“☑️在此处粘贴替换”**：

- App ID：替换app_id对应标记。
- App Secret：替换app_secret对应标记，由用户自己填写。
- 记录接口URL：替换新增记录POST地址对应标记，使用自己的副本接口地址。

把对应值完整替换标记，不保留“☑️在此处粘贴替换”文字，不改其他动作。记录接口由副本app_token/table_id拼成，网页地址与作者模板ID不能代替。按实际动作核对文本字段“文本内容”、默认支出；首次截图/照片/网络授权按手机提示完成。

本Skill不内置私人快捷指令分享ID。若未看到三处标记，先核对配套版本及无凭据动作。直接点击编辑和右上角播放指配套版本配置页面；实际页面不一致时据其界面排错，不编造按钮位置。

## 5. 右上角播放测试

参数填好后，**点击右上角播放标即可测试**。屏幕可显示任意便于OCR的内容，不要求固定测试句子、金额、商户或唯一标记，也不要求真实付款。

按 [验收规则](verification.md) 核对本人副本新增记录的“文本内容”出现此次OCR文字，就确认截图→OCR→表格基础链路成功。金额/项目/分类属于后续字段提取及Agent备用验收，不作为手机文本写入的强制门槛；不因金额还没出来反复点击播放。

普通测试数据按真实record_id登记排除；若使用真实消费截图，该账单正常保留统计，不自动当测试排除。无法判断是否真实账单时只问这项必要信息，不强迫重拍固定文本。

## 6. 安装最后一步：飞书CLI与授权

复制模板、创建发布应用、添加文档应用、填写快捷指令参数，并确认手机OCR文本已同步后，再进入这一安装步骤；开头不设置第0步，也不提前安装、登录或核查CLI权限。

此时说明：“截图记账已经跑通。后续日报、周报和Agent补全，默认通过飞书CLI读写账本；现在检查电脑或实际执行端是否已有，已安装可用就直接复用，没有再安装，同时核对登录账号和账本权限。”

按 [CLI接入](agent-cli.md) 每轮推进一项：

1. 检查lark-cli可执行及版本；已有可用则复用，缺失再检查Node.js/npm并按官方安装。路径或宿主限制先排查，不直接覆盖重装。
2. 检查登录有效性；缺失或过期才引导配置/授权，不在聊天收Secret或token。
3. 确认与复制、使用账本的同一飞书账号及组织；昵称相同或能读共享账本不足以证明一致，不静默换bot或另一个账号。
4. 读取本人副本的schema及目标记录，验证读取权限；再按适当原记录更新并读回验证更新权限，dry-run和登录成功不能代替实际验收。

这些结果分别保存。只有CLI、登录、预期账号及目标读取通过，才启用正式日报；自动OCR补写还需更新验收。已完成配置的用户复用进度，不重走手机步骤。

云端Agent检查其实际执行端或已接通的本机CLI。仅用户明确选择且已验收的原生等效方案才记录替代，不因品牌不同跳过。基础手机尚未跑通时，回到相应基础步骤，不把CLI检查前置。

## 7. 日报周报

提醒截图默认支出、收入单独告诉Agent。先复核CLI登录仍有效、账号匹配已确认、目标账本读取权限已验证，再验证实际Agent能读取本人OCR，按 [OCR补全](ocr-fallback.md) 单独检查缺项更新与读回；只有没有金额证据的测试文本时，不能宣称备用金额提取已通过。只问每周预算，持久保存后按 [自动化](automation.md) 配置真实任务。

日报默认回到本会话。捕获实际conversation_ref并把它设为后台任务投递目标，立即测试是否回到同一会话；改名字/置顶不自动赋予投递能力。宿主不支持时说明会话内投递待配置，不假称已启用、不擅自改成群聊。

## 8. 收尾：手机入口与会话

基础文本写入跑通后，给出两种快捷入口，按机型选择：

- 轻点背面：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下（或三下） → 截屏记账。
- 支持操作按钮的机型：设置 → 操作按钮 → 快捷指令 → 选择“截屏记账”；之后按住操作按钮执行。iPhone 15 Pro/Pro Max及后续配备操作按钮的机型可用；iPhone 15/15 Plus不支持，不写成所有“15以上”都能绑定。这里指操作按钮，不是电源/锁屏侧边按钮。已有入口可直接复用，不强迫再次设置。

随后主动建议：**“建议把本会话改名为‘记账日报’并置顶，后续记账和查看日报更方便。”** 同会话投递实测通过，再补“后续日报会直接发在本会话中”；否则说明实际投递状态和待完成步骤。这是建议，不在用户未要求时自动改名或置顶。

来源：[Apple操作按钮设置](https://support.apple.com/zh-cn/guide/iphone/iphe89d61d66/ios)。机型与设置入口按当前设备核对。
