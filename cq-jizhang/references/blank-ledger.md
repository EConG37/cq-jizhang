# 创建自己的空白账本

公开版不附作者飞书链接。已有本人账本时复用，不清空记录；有经用户核验的脱敏模板时也可整份复制到本人云空间。没有时按下面创建，不需要等待作者提供资源。

## 飞书界面创建（默认）

在飞书云文档新建一个空白多维表格，命名「我的记账本」，把数据表命名「具体开支」。创建六列，复用初始列并改名，避免产生额外的第七列；不删除已有账本的数据列。

| 字段 | 类型与配置 |
|---|---|
| 文本内容 | 多行文本，主字段；接收手机 OCR |
| 日期 | 日期，显示日期和时间；新增时默认当前时间，保留可编辑以便历史补记 |
| 收支类型 | 单选：支出、收入；默认支出 |
| 金额 | 数字，保留两位小数；不设置为 0 的默认值 |
| 具体花费项目 | 文本 |
| 消费类型 | 多选：饮食、交通、生活花费、零食、会员费、无匹配类别 |

先保留普通可编辑的金额、项目和分类字段，随后在当前飞书界面为它们配置字段捷径/AI 提取，来源为「文本内容」。金额提取实际支付人民币数值，项目取具体购买内容，分类限于已有选项；多笔金额不清、退款或币种不明时留空待核对。界面或权益不支持字段捷径时，如实记录主链路不可用，在后续 Agent 实际读写通过后使用其补全能力。

查看当前字段设置并说明实际触发条件，不承诺创建普通字段就等于 AI 已启用。不要把金额改成只读公式来代替可更新字段。

保留主表格视图并命名「开支记录」。需要手动录入时增加「表单」，需要分类浏览时增加「账户记录」表格视图；它们共享同一张表，不建三份独立账本。可增加本人专用「仪表盘」，用支出筛选后的金额求和展示消费，用分类汇总查看去向，收入单列；只有空容器不能说仪表盘已配置。视图和仪表盘不阻挡手机基础写入，按使用者需要补齐。

复制本人「具体开支」页面的链接给 Agent。核对真实 schema、单选和多选选项，再拼记录 API 地址。此阶段不强制先装 CLI，仍先完成手机 OCR 入表测试。

## 已有可用 CLI 时的 Agent 创建方式

仅用户已授权创建本人账本、且当前 CLI 已登录可用时，才直接创建；没有现成 CLI 则继续界面方式，CLI 安装保留在手机测试后的阶段。执行前查当前 `--help`，字段定义见 [ledger-fields.json](../assets/ledger-fields.json)。

用宿主的进程参数数组传递读取并序列化后的字段 JSON，不手工拼接 shell。命令形态：

```text
lark-cli base +base-create --name 我的记账本 --table-name 具体开支 --time-zone Asia/Shanghai --fields <序列化字段JSON数组> --as user
```

保存实际返回的 Base/表 ID。创建状态未知或部分成功时先查询，不盲重试；不调用任何作者模板。CLI v3 使用字符串类型 `text/datetime/select/number`，不要把此 JSON 直接用于旧 v1 字段创建 API。

这里的日期默认值是可编辑的 `datetime + record_created_time`；如果用户现有字段是只读创建时间，历史补记需先说明口径。显示顺序可在视图中设为日期、文本内容、收支类型、金额、具体花费项目、消费类型；主字段固定在首位时接受平台限制。
