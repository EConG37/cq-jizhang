# 验收与故障排查

手机新增、Agent读取、AI提取/备用更新、会话投递分阶段验证，不能互相替代。

## 基础安装测试：只验证OCR文字入表

在作者标记版编辑页面填好三处参数，**点击右上角播放标一次**。使用用户当前屏幕即可，文本不限制，不指定固定句子、金额或标记，不要求真实付款。

核对成功响应及record_id（手机原生HTTP按code，CLI按ok与退出码），或本人副本真实出现对应新增记录；读回“文本内容”与本次手机OCR对应，即shortcut_write_verified=true。不用金额/项目/分类是否已生成来决定手机通路成败。OCR可能有识别误差，只确认识别结果已正确传入，不声称与图片内容逐字无误。

优先用返回record_id定位；无ID时结合本次点击时间、OCR片段与此前记录辨认。必要时让用户指出刚新增的行/记录链接，不要求改成固定测试文本。无读取工具可用用户脱敏可视结果核对，标“用户可视核验”，agent_read_verified仍未通过。

非真实消费的测试记录按具体ID排除、不自动删除；真实消费截图正常计账，不因发生在安装测试阶段就排除。无法判断时仅确认是否真实账单。没拿到ID不能按文本关键词批量排除，待补定位。

新增成功但金额空白只说明“文字已同步，金额待提取”。给第一层字段捷径处理窗口，未满120秒记录首次观察时间后续再执行；接着按 [OCR补全](ocr-fallback.md) 处理。不重复POST催AI，也不强制把安装测试改成0.01元。

POST超时或状态未知，先按record_id或本次点击时间/OCR片段查询是否已存在；无查询工具让用户查副本。确切失败、排错且确认原记录不存在后最多重试一次，再失败停在当前步骤。不能因为金额没有出来就重试新增。

CLI模式核对宿主运行位置、身份、编辑权限；按 [接入说明](agent-cli.md) 转换NDJSON单选值、检查分页，不把仅CLI存在当授权通过。

## 安装最后一步的CLI、账号和权限检查

先完成复制模板、应用授权、参数填写和手机OCR同步测试；随后在安装最后一步说明默认日报/周报需要CLI；已装可执行不重装，缺失安装后检查版本。auth有效与账号匹配分别验证，昵称/共享账本可读不是同账号证明。本人副本及手机测试应已完成，再读取真实schema/记录检查目标读取；未完成基础步骤则先继续基础安装。适当原记录更新并读回后才标目标更新权限，不能以dry-run代替。默认用户身份且组织正确，错账号不启用日报、不默默改bot。只保存检查结果到使用者自己的私有配置，交付示例不含任何人账号资料。详见 [CLI账号检查](agent-cli.md)。

## AI提取与第二层备用验收

与手机基础写入分开记录。第一层字段捷径结果齐全时，不人为清空真实账单制造缺项。备用验收使用用户现有的有明确金额/项目语义且自然缺项的记录，或明确隔离的演练记录；需暂改AI配置先展示具体调整，由用户确认实施和恢复，不把它当普通安装的必做操作。

原生窗口过去后，当前Agent分析该记录OCR、只更新同record_id尚缺的金额/项目/分类，再读回并在后续原生运行后核对。按OCR实际金额检查，不规定0.01元。记录数不增加，原文、日期、收支类型及已有有效值保持。实际通过才设agent_update_verified/ocr_fallback_verified=true；任意测试文本若无金额证据，备用金额提取仍待验收，不能猜值以完成流程。

只有更新工具/权限缺失则继续技术引导；有歧义标待核对。备用未跑通不撤销已成功的手机文字入表检查；可先用可用第一层报告，但明确缺项备用待完成。

额外规则：金额0不是空；仅类别缺失只补类别；OCR变更旧提案失效；多笔实付/退款不猜；状态未知先查不重复新增。报告前重读，缺金额只给已知小计与待核对数量。

## 报告与同会话投递

先复核实际CLI身份、登录有效及预期账号一致，再由实际报告身份读取目标范围，样报核对收支分开、测试ID仅排除非真实测试。空表发“暂无真实账单”，不伪造消费。

持久保存实际conversation_ref，真实任务建立/更新→核对启用/下次运行→立即执行→核对执行日志及日报出现在原会话。只有后台结果、系统通知或其他会话消息，不算same_conversation_delivery_verified；不能承诺日报回本会话。接收通道已验证可分别记delivery_verified，但同会话投递仍待完成，明确区分。

收尾建议改名“记账日报”并置顶；该建议已显示只表示conversation_suggestion_shown，不代表用户已经改名/置顶或投递成功。

## 按现象排错

| 现象 | 检查 |
|---|---|
| 找不到添加应用 | 本人副本右上角「・・・」更多→添加文档应用；不从分享/协作者添加 |
| 没看到三处填充标记 | 核对作者当前标记版；看脱敏动作，不要求用户暴露Secret |
| 鉴权失败 | ID/Secret填反、未完整替换标记、空格、应用发布及鉴权动作 |
| 新增被拒绝 | 新增scope、版本发布、文档应用已添加及副本编辑权限 |
| 写错表 | 本人app_token/table_id对应“具体开支” |
| 有OCR但金额空白 | 基础文字写入已经成功；检查第一层窗口/配置，再执行第二层补原记录 |
| Agent补不进去 | 当前身份更新权限、字段可写性、原生后续覆盖，未验收不称备用可用 |
| 手机成功Agent读不到 | Agent账号、副本权限、CLI/原生工具数据范围 |
| 报告没回原会话 | 实际任务conversation_ref、宿主投递能力、原会话消息与执行回执 |
| 找不到操作按钮设置 | 检查是否支持该按钮的机型；可用轻点背面，不尝试电源侧键 |
| 收入被当支出 | 截图默认支出；文字补记显式收入并读回 |
| 收入被AI覆盖 | 修复实际字段配置或人工核对，不反复争抢写入 |
