# CQ-jizhang｜飞书记账引导与消费管家

公开版可从零使用：没有账本按 [空白账本](references/blank-ledger.md) 创建；没有快捷指令按 [手机创建步骤](references/shortcut-build.md) 引导。已有本人配置优先复用。先完成手机基础写入，再安装或核验 CLI；不索要作者的链接、账号或配置。

## 默认提取顺序：固定两层

手机先将截图OCR文字写入“文本内容”。**第一层是飞书字段捷径AI；第二层是用户当前选定且已接通的Agent。** 云端/本地、豆包工作/Coze/WorkBuddy/ZCode/Codex等均属于同一个第二层，不按厂商再排先后、不自动逐个平台尝试。字段捷径已正确补全时，Agent不重复提取；超过处理窗口仍缺金额、项目或分类时，才由第二层补原记录。第二层也不能处理或文字有歧义则待核对，详见 [OCR补全](references/ocr-fallback.md)。

安装后由用户第一次调用启动引导；安装文件本身不会执行、取得权限或启动定时任务。账本使用飞书＋iPhone，消费管家优先复用用户当前选定的Agent及其模型额度，不强制豆包工作。WorkBuddy、ZCode、Codex等桌面宿主与Coze云端接入按 [当前Agent与飞书CLI](references/agent-cli.md) 引导；默认日报流程仍检查CLI；用户明确选择已验证原生等效方案时记录例外。手机OCR入表通过后再确认执行位置、CLI/连接器、身份及真实调度，不自动安装另一个Agent。

## 首次接待与续接

先读取当前用户的非敏感配置进度，复用已完成的步骤。没有进度时从建立本人空白账本开始；用户已有经核验的脱敏模板时可复制。手机OCR入表测试通过后，才进入安装最后一步的CLI检查；按 [新手引导](references/onboarding.md) 每次只给一个可执行步骤，说明入口、操作、完成标志，再检查结果推进；用户想看完整教程时提供 [公开教程](assets/公开教程.md)。不要一次倾倒全部步骤，不要每步重新问是否授权已要求的配置。

消费偏好只主动问一个问题：**“你每周大致想把支出控制在多少元？”** 在写入和读取验收后询问；前面已提供则不重问。预算可为0，可稍后设置，不追问月收入、月限额、固定开支、储蓄目标或分类预算。技术上无法推进时，只收集必要的副本链接、步骤完成情况、脱敏错误或接收目标。

首次和进入日常模式时都明确提醒：**“通过 iOS 快捷指令截图记录的账单默认都是支出。如果有收入，可以单独告诉我，例如‘今天收到工资5000元’，我会按收入记录，不抵扣消费预算。”**

## 配置与验收

1. 复用用户账本；没有时按 [空白账本](references/blank-ledger.md) 创建六列和需要的视图/仪表盘。普通字段不等于已配置字段捷径；分别核对主链路能力，不写入任何作者模板。
2. 引导创建自己的企业自建应用、开通新增记录权限、发布版本；添加应用只走账本副本右上角「・・・」更多菜单→添加文档应用，并核对编辑权限；按实际接口补充读取权限。机器人消息能力仅在宿主确实需要时配置，不要求webhook。
3. 按 [凭据填写对照](references/credentials.md) 填本人快捷指令参数；缺少安装资源时直接按 [手机创建步骤](references/shortcut-build.md) 从零建立。标记版的App ID、App Secret、记录接口URL三处“☑️在此处粘贴替换”需完整替换。副本app_token/table_id用于拼记录接口地址。Secret不发聊天、不存进状态或报告；用户自己填入手机。应用身份与Agent用户授权分别验证。
4. 按 [测试与排错](references/verification.md) 让用户点击编辑页面右上角播放标一次，文本不限制。本人副本“文本内容”同步此次OCR即通过手机写入；金额/项目/分类与Agent读回、备用更新另行验收，不要求固定0.01元或唯一标记。只有非真实消费的测试ID排除；真实账单正常统计，不自动删除。
5. 安装最后一步：手机文字入表成功后，先说明日报/周报需要CLI，按 [CLI安装与授权](references/onboarding.md#6-安装最后一步飞书cli与授权) 检查已有则复用、缺失则安装、登录有效、同一账号/组织以及副本读写权限，不擅自重装或清除凭据。随后按 [OCR双链路补全](references/ocr-fallback.md) 验证Agent更新原记录：手机已完成OCR，Agent读取“文本内容”，原生AI留空时补金额、具体花费项目、消费类型。检查实际更新权限、AI字段可写性和延迟覆盖；备用写回未通过就标待完成。进入消费管家配置，只问每周预算，并保存非敏感进度。使用 [日常Agent指令](assets/agent-prompt.md) 和 [自动化接入](references/automation.md) 生成样报、配置真实任务。用户已要求成功后开启，不再加泛泛的“是否开启”确认；接收者无法确定时才补问。
6. 核对任务启用状态、下次运行时间，并立即执行一次核对报告能否回到本会话；保存实际conversation_ref，不能用其他会话消息代替同会话验收。默认北京时间每天22:00日报，周日同一条附周报及下周计划；其余日期只发日报。无月度问卷、无默认月度任务、无全天高频轮询。

## 安装最后一步：Agent与飞书CLI

手机OCR入表通过后，在安装最后一步识别当前宿主，桌面/其他CLI宿主按 [Agent接入](references/agent-cli.md) 检查CLI安装、授权和读写，Coze云端优先检查官方本地目录连接能否执行本机CLI，其次检查云端执行环境或已部署CLI服务桥接。当前会话自己理解OCR、使用当前会话/项目模型额度；CLI负责读写，不调用飞书AI重跑提取。缺少认证时逐步指导，不把CLI存在说成账本权限已通过。消费偏好仍只问周预算。

## 完成标准与状态

分别记录 `template_copied / app_published / document_authorized / shortcut_configured / shortcut_write_verified / account_match_verified / ledger_read_permission_verified / ledger_update_permission_verified / agent_read_verified / agent_update_verified / ocr_fallback_verified / report_ready / schedule_active / delivery_verified / same_conversation_delivery_verified`。`template_copied`兼容旧状态名，公开版表示本人账本已创建或复制并核对六列，不声称复制过作者模板。状态落到用户专属的持久设置或工作区，参照 [状态结构](assets/setup-state.example.json)；示例false不是验证结果。云端预算和设置必须能被下一次定时任务重新读取，仅对话记忆不够。只保存ID、进度、预算、时间、身份、任务和验证结果，不保存凭据或账单全文。

原生AI未提取时优先执行Agent OCR补全；Agent无法运行、字段不可写或提取有歧义时转原记录人工核对。空白不是额度耗尽的充分证据，豆包工作不保证额度独立，外部宿主备用推理按所选Agent自身用量计费；缺少读取或实际调度能力时继续引导补齐，不把“能写入”说成“日报已启用”。预算稍后设置可先启用无预算日报周报，不编造预算提醒。

完成时给账本链接、CLI安装/登录/账号一致/账本读写权限、手机OCR入表/Agent读取/备用更新各自状态、周预算或未设置、任务ID/下次执行及实际投递位置。按 [收尾步骤](references/onboarding.md#8-收尾手机入口与会话) 提供轻点背面和支持机型的操作按钮入口，建议将本会话改名“记账日报”并置顶。只有同会话投递实测通过才承诺日报直接发在本会话；未执行步骤标待完成，不自动替用户改名/置顶。

已有账本切换Agent时复用配置，先核验旧日报/补全任务已停，再让新Agent接管；同一账本只指定一个调度负责人，避免重复补写和推送。

## 日常使用

遵守 [日常Agent指令](assets/agent-prompt.md)；文字收入和支出补记按 [补记规则](references/income.md)。用户明确的“帮我记”“今天收到工资”等才是记账请求；闲聊、预算计划和未来预计收入不新增。明确且字段足够的收入请求直接写一次，不强制二次确认；歧义或修改历史记录才追问。

报告或消费查询前先补全，重新读取后按六列数据统计，收入不抵扣周预算。分页读全，相同record_id去重；不同ID疑似重复只提示；多分类归到一个待核对组。原日期可能是录入时间，历史补记需要准确日期。AI字段不等于可任意编辑：原生AI覆盖收入金额/项目时，检查读回并修复实际字段配置或转人工核对，不以含糊文本充当结构化成功。

CLI Base v3读值先按接入参考转换协议，收支单选数组不能直接喂给旧v1格式脚本。读取值和写入协议分别核对。有Python工具时，可用 `scripts/weekly_summary.py` 对完整读取的飞书记录做确定性汇总；没有Python则用宿主计算工具执行相同规则。这些辅助脚本不连接飞书、不创建调度。交付包仅含当前六列流程需要的资源。

触发示例：`使用 $cq-jizhang，从零带我配置飞书截图记账，成功后开启日报周报。`；`继续上次配置`；`检查本周有OCR但金额没出来的账单，补齐原记录`；`记一笔收入：今天工资5000元`；`这周花了多少钱`；`每周预算改成800元`。
